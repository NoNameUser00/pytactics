# 🤖 PyTactics — аркада по информатике: Python + алгоритмы

Пошаговая стратегия на карте в стиле **CodeCombat**.
Главная — **карта вселенной** (`index.html`): 3 галактики, 8 планет-уровней.
Ученик пишет **настоящий Python-подобный код**, герой выполняет его на поле,
враги ходят в ответ. Работает **на GitHub Pages без сборки** — только статика.
Вход через **Supabase** (проект `informatika`) — прогресс класса в облаке;
без входа игра тоже работает (прогресс в браузере).

## 🎮 Играть локально

Открой `index.html` (вселенная) → выбери планету → попадёшь на арену `game.html?level=N`.
Без интернета и без Supabase — тоже работает (гостевой локальный режим).

## 🎮 Играть локально

Просто открой `index.html` в браузере (двойной клик). Интернет не нужен.

## 🚀 Деплой на GitHub Pages

1. Создай репозиторий, залей файлы:
```bash
git init
git add .
git commit -m "PyTactics game"
git branch -M main
git remote add origin https://github.com/USERNAME/pytactics.git
git push -u origin main
```
2. В репозитории: **Settings → Pages → Deploy from a branch → Branch: `main`, folder: `/ (root)`** → Save.
3. Игра будет на `https://USERNAME.github.io/pytactics/`.

> Файл `.github/workflows/static.yml` тоже добавлен — Pages заработает автоматически.

## 📚 Концепция игры

**Название:** PyTactics: Алгоритмы Грида
**Сеттинг:** Станция «ГРИД» захвачена багами-вирусами 👾. Ты — оператор робота 🤖, пишешь Python, чтобы собрать кристаллы 💎 и дойти до портала 🌀.

**Цикл обучения (каждый уровень):**
```
1. Брифинг → 2. Пишешь код → 3. ▶ Запустить →
4. Смотришь пошаговый бой → 5. Ошибка? Читай консоль + 💡 Подсказку →
6. Победа ⭐ → Следующий уровень
```

**Прогрессия — главы учебника (уровень = параграф):**

| Глава | Планеты | Тема Python |
|---|---|---|
| 1. Первые программы | 1–4 | `print()`, структура, `#`, переменные в выводе |
| 2. Переменные | 5–9 | имена, `=`, `bool`, `int()/type()`, `del` |
| 3. Операторы | 10–15 | арифметика, `// %`, строки, `len()`, `+= *stmt` |
| 4. Циклы и условия | 16–21 | `if/else`, `for range`, `while`, `break`, финал «Уровень доступа» |

**Аркада (пошаговая стратегия):**
- Карта 8×10, туман не нужен, всё видно.
- Каждый `move_* / attack / collect / wait` = **1 ход**. После твоего хода ходят враги.
- Враг рядом → бьёт −3 энергии. Энергия 0 → поражение.
- Победа: собрать **все 💎** + встать на **🌀**.
- ⭐: 3 звезды — победа + оптимальные ходы + короткий код, 2 — победа, 1 — победа с подсказкой-решением.

**API героя (то, что можно вызывать в коде):**
```python
move_up() / move_down() / move_left() / move_right()
attack("up")  # направление: "up","down","left","right"
collect()     # собрать кристалл под ногами
wait()        # пропустить ход

# сенсоры (хода не тратят):
is_wall("up") / is_enemy("up") / is_crystal("up") / is_exit("up")
get_x() / get_y() / get_energy() / crystals_left()
print("текст")  # вывод в консоль
```

## 👩‍🏫 Для учителя
- Подсказки 3-уровневые: намёк → псевдокод → решение (со штрафом к звёздам).
- Прогресс хранится в `localStorage`, можно сбросить кнопкой.
- Код ученика проверяется не по тексту, а **по результату симуляции** — читерство «захардкодить» невозможно, карта требует настоящего алгоритма.
- Можно добавлять уровни: скопируй объект в `js/levels.js`.
