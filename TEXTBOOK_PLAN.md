# Учебник → Вселенная (ПЕРЕЙТИ ПОЗЖЕ, пока не делать)

Источник: `_media_books_python-na-primerah-praktika-praktika-i-tolko-praktika.pdf`
(338 стр., «Python на примерах. Практика, практика и только практика»).

## Правило отображения (от пользователя)
- **Глава учебника = галактика** на карте вселенной
- **Параграф главы = планета** в этой галактике
- **Задания параграфа = задачи** на самой планете (арена)

## Что известно сейчас
- Глав: 16 + приложение («Список использованных источников» в конце).
- Параграфы: нумерация вида X.Y (планеты), подпункты X.Y.Z — кандидаты в отдельные
  задачи планеты или её этапы.
- Текущие 8 демо-уровней (`js/levels.js`) — временные, позже заменить/перенастроить
  под главы 1–N учебника.
- Замки планет сейчас: планета N открыта, если есть звезда за N−1. При переходе
  на учебник правило сохранить (внутри галактики — по порядку параграфов).

## Техдолг перед переходом
1. Названия глав/параграфов из PDF не извлекаются программно (в шрифтах нет
   ToUnicode — и закладки, и текст битые). Достать вручную глазами или OCR.
2. Выбрать, какие главы идут в школьный курс (16 — много; 13–16 — исключения,
   ООП, БД, многопоточность — вероятно, вне базы).
3. Перенести контент в `js/levels.js`: поле `book: "гл.4 §4.2"` у каждого уровня,
   группировка галактик по главам в `js/universe.js` (сейчас GALAXIES захардкожены).
4. Задания учебника переписать под API героя (move_*/attack/collect/сенсоры).
